# 买方择时模型（timing）

在 `daily_report` 四维体检的基础上，新增**买方视角的择时决策层**，把"数据"升级为"可执行信号"。

## 运行方式

```bash
# 完整运行（采集 + 评分 + 沉淀 + 回测）
.venv/Scripts/python.exe -m timing.run

# 只跑回测（不联网采集估值/资金数据，更快）
.venv/Scripts/python.exe -m timing.run --backtest-only
```

## 三大能力

### 1. 择时评分（`engine.py`）
把四维数据合成一个 **0~100 的「市场机会分」**，替代原来简单"数灯"的判定：

| 维度 | 权重 | 打分逻辑 |
|------|------|---------|
| 估值 | 35% | PE 分位越低越便宜，得分越高（锚，决定长期胜率） |
| 技术 | 15% | 距前高回撤越深位置越低，得分越高 |
| 资金 | 20% | 杠杆资金撤离 → 扣分；情绪亢奋 → 扣分 |
| 情绪 | 30% | 逆向：恐慌度越高越接近买点，得分越高 |

输出：机会分 + 分维度得分 + **仓位建议**（含"杠杆撤离时控节奏"的冲突裁决）。

### 2. 历史沉淀（`backtest.py`）
每次运行把评分追加到 `history/timing_history.csv`，形成连续信号序列，
用于观察模型信号演变、后续做更严谨的回测。

### 3. 回测验证（`backtest.py`）
用指数历史 K 线验证「估值低 + 趋势转好（站上 MA60）」双确认择时规则的历史表现。

## 回测的诚实结论（重要）

近 3 年（2024-2026）属单边下跌市，回测显示：

- **择时策略收益跑输满仓持有**（因为熊市里"越跌越买"会持续被套）；
- 但**最大回撤显著收窄**（如创业板 -31% vs -45%、科创50 -32% vs -47%）。

这证明买方择时的核心价值是**控回撤、活下来**，而非"赚更多"。
单边熊市应降低仓位预期，等右侧趋势确认后再加仓，避免接飞刀。

## 模块结构

| 文件 | 职责 |
|------|------|
| `engine.py` | 四维打分 + 综合机会分 + 仓位建议 |
| `backtest.py` | 历史 CSV 沉淀 + 估值/趋势择时回测 |
| `html.py` | HTML 可视化渲染 |
| `run.py` | 主入口 |

> ⚠️ 本模型基于公开数据量化，仅供研究参考，不构成投资建议。
