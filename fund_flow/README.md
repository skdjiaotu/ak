# 资金面监控 —— 北向资金 · 融资融券

穿透「官方一片欣欣向荣」的表象，看真实的资金动向。

## 运行方式

```bash
.venv/Scripts/python.exe -m fund_flow.run
```

## 模块结构

| 文件 | 职责 |
|------|------|
| `fetcher.py` | 数据采集：北向资金（东财 stock_hsgt_hist_em）+ 两融每日汇总（东财 RPTA_RZRQ_LSHJ） |
| `engine.py` | 分析引擎：杠杆趋势、情绪热度、外资态度、综合判定 |
| `run.py` | 主入口 + 报告输出 |

## 核心洞察：数据本身就是「假象」的证据

### 1. 北向资金净买入已停止披露（2024-08-19 起）

这是最重要的事实。沪深交易所自 2024-08-19 起**停止披露北向资金每日净买入**，
改为只披露成交总额。东财接口里「当日成交净买额」字段从此全部为 NaN。

**这意味着官方主动隐藏了外资的真实净流向** —— 散户无法再直接看到外资在买还是在卖。
本模块会显式暴露这一事实，并用「停更前最后数据」+「持股市值」间接推断。

### 2. 字段单位（易踩坑）

| 字段 | 单位 |
|------|------|
| 当日成交净买额 | 亿元 |
| 买入/卖出成交额 | 亿元 |
| 历史累计净买额 | 万亿元 |
| 持股市值 | 元 |

### 3. 融资融券（仍完整公开，最可靠）

两融数据每日完整披露，是判断杠杆资金态度的硬指标：

- **融资余额**：杠杆做多规模，趋势上升 = 加仓，下降 = 去杠杆撤离
- **融资余额/流通市值**：杠杆水位（>3.5% 过热，<2% 谨慎）
- **融资买入额/融资余额**：单日杠杆换手，>6% 情绪亢奋
- **融券余额**：做空力量（2024 年起受监管限制，趋势性萎缩）

## 判定逻辑

- 融资余额 20/60 日变化 → 杠杆资金趋势
- 融资余额近 3 年分位 >90% → 杠杆水位偏高警示
- 外资停更前 60 日净买入 <0 且持仓市值上涨 → 「边涨边卖」警示

## 数据源说明

- 北向资金：`akshare.stock_hsgt_hist_em`（东财，2779 条，2014 至今）
- 两融汇总：东财 `datacenter-web.eastmoney.com` RPTA_RZRQ_LSHJ（3000+ 条，2014 至今）

网络注意：本机需绕过系统代理（`trust_env=False`），东财域名对代理不稳定。
