# A 股机械化仓位 / 止损纪律手册

> 基于「每日市场体检」四维信号（估值分位 + 资金面 + 恐慌波动率 + 危险度评分）自动推导。
> 原则：**不预测、不凭感觉，只按信号执行**。信号变了，动作就变。
> 本手册仅供研究参考，不构成投资建议。

---

## 一、信号 → 仓位 总映射表（核心）

每天收盘后跑一次体检，按下表机械调仓，**禁止跳过任何一条**。

| 综合信号 | 红灯数 | 黄灯数 | 权益仓位上限 | 现金/债券下限 | 情绪基调 |
|---|---|---|---|---|---|
| 🔴 高风险 | ≥2 | — | **≤ 30%** | ≥ 70% | 防御，只做减仓不做加仓 |
| 🔴 高风险 | 1 | ≥3 | **≤ 40%** | ≥ 60% | 防御，不新增仓位 |
| 🟡 需警惕 | 0 | ≥4 | **≤ 50%** | ≥ 50% | 谨慎，只做已有标的的减仓/换仓 |
| 🟡 需警惕 | 0 | 3 | ≤ 60% | ≥ 40% | 谨慎，精选标的 |
| 🟢 相对安全 | 0 | ≤2 | ≤ 80% | ≥ 20% | 中性偏多，可分批布局 |

> 仓位指的是**权益类总仓位**（股票+偏股基金），不含货币/债基。

## 二、三条「强制降仓」红线（任一触发，无条件执行）

这四条是最高优先级，**不管其他信号多好都要执行**：

| 红线 | 触发条件 | 动作 |
|---|---|---|
| **杠杆撤离线** | 融资余额 20日 < -8% 且连续 ≥2 个交易日 | 权益仓位降至 ≤40%，停止一切融资/加杠杆 |
| **极度恐慌线** | 任一宽基波动率分位 ≥ 91% | 该指数相关持仓减半；全市场 ≥2 个指数极度恐慌则总仓位 ≤40% |
| **估值见顶线** | 任一持仓对应指数 PE分位 ≥ 90% | 该指数相关持仓**清仓/大幅减至 ≤10%** |
| **红灯触发线** | 综合信号 = 🔴 高风险 | 当日收盘前权益仓位压至 ≤30% |

## 三、个股 / 指数止损纪律（机械执行）

| 情形 | 止损规则 |
|---|---|
| 单笔持仓浮亏 | **-8% 无条件止损**，不补仓、不问原因 |
| 单笔持仓浮盈回吐 | 从最高点回撤 **-10%** 止盈离场 |
| 指数高位追入 | 若买入时该指数 PE分位 ≥80%，止损收紧到 **-5%** |
| 破位止损 | 收盘价跌破 20 日均线且 20 日均线走平/向下 → 减半仓 |
| 杠杆仓位 | 融资买入部分 **-5% 强制平仓**，绝不扛 |

---

## 四、加仓 / 建仓纪律（只在绿灯下允许）

| 前置条件 | 动作 |
|---|---|
| 综合信号 🟢 + 该指数绿灯 | 可分批建仓（单指数首次 ≤ 总仓位 10%，分 3 批） |
| 综合信号 🟢 + 该指数黄灯 | 只观察，不新建仓 |
| 杠杆资金连续 ≥3 日净流入 + 综合 🟢 | 才允许动用融资，且融资比例 ≤ 总资产 20% |
| 任何红灯/黄灯 ≥4 的日子 | **禁止任何新增买入**（含定投加仓） |

## 五、每日执行清单（打印贴在显示器旁）

每天收盘后按顺序勾选，**全部勾完才算完成当日纪律**：

- [ ] ① 跑体检脚本：`.venv/Scripts/python.exe -m daily_report.run`
- [ ] ② 记录当日：红灯 __ 个 / 黄灯 __ 个 / 绿灯 __ 个
- [ ] ③ 对照「仓位总映射表」核对今日仓位是否超标 → 超标则当日或次日开盘前减到位
- [ ] ④ 检查四条「强制降仓红线」是否触发 → 触发立即执行
- [ ] ⑤ 检查持仓是否触发止损线 → 触发不犹豫，机械执行
- [ ] ⑥ 确认今日是否违规买入（黄灯≥4 / 红灯日禁止买入）→ 违规需复盘记录原因
- [ ] ⑦ 把结论写入复盘日志（当日信号 + 做了什么 + 为什么）

## 六、纪律的「反人性」要点

1. **信号是滞后的，但纪律必须前置**：不因为"感觉要涨"而跳过减仓。
2. **止损是保护，不是认错**：-8% 止损是你还能活着的唯一原因。
3. **空仓也是一种仓位**：红灯/高黄灯时，持有现金不丢人。
4. **杠杆只在绿灯+资金流入时用**：其余任何时候，融资都等于自掘坟墓。
5. **宁可少赚，不可多亏**：长期存活率 > 单次收益率。

## 附：当前阈值速查

| 维度 | 危险阈值 |
|---|---|
| 综合危险度分 | 红灯 ≥70；黄灯 40~70；绿灯 <40 |
| PE 分位强制信号 | ≥90% 红；≥60% 黄（即使技术超跌也不给绿灯） |
| 波动率恐慌 | ≥91% 极度恐慌；86%~91% 恐慌 |
| 杠杆撤离 | 融资余额 20日 < -8% 连续 2 日 |
| 情绪亢奋 | 融资余额/流通市值 > 6% 单日换手 |
