# 每日市场体检报告

一键整合四维数据，输出 A 股市场「位置高低 + 危险程度」的完整体检。

## 运行方式

```bash
.venv/Scripts/python.exe -m daily_report.run
```

运行后：
1. 终端输出四维全景文本报告
2. 生成 HTML 可视化报告到 `reports/每日市场体检_YYYY-MM-DD.html`

## 四维框架

| 维度 | 数据源 | 回答的问题 |
|------|--------|-----------|
| ① 估值分位 | 蛋卷基金（index_risk） | 贵不贵 |
| ② 技术结构 | 新浪 K 线（index_risk） | 位置高不高 |
| ③ 资金流向 | 东财两融 + 北向（fund_flow） | 钱真在进吗 |
| ④ 恐慌情绪 | 新浪 K 线波动率（vix） | 市场疯没疯 |

## 综合判定规则

- **🔴 高风险**：≥2 个宽基指数亮红灯
- **🟡 需警惕**：≥1 个红灯，或 ≥3 个黄灯
- **🟢 相对安全**：多数指数绿灯

资金面独立附加警示：杠杆资金撤离时，无论指数信号如何都会提示「警惕去杠杆」。

## 模块结构

| 文件 | 职责 |
|------|------|
| `engine.py` | 整合 index_risk + fund_flow + vix，输出统一数据结构 |
| `html.py` | HTML 可视化渲染（遵循 A 股红涨绿跌惯例） |
| `run.py` | 主入口 + 文本报告输出 |

## 定时任务

建议每天 A 股收盘后（15:30）自动运行一次。已配置定时任务后无需手动执行。
