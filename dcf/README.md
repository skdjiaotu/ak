# DCF 估值模型

投行级 FCFF 自由现金流折现估值模型（Python 实现），支持 A 股 / 港股上市公司，
自动从东方财富公开接口抓取历史财务数据，推导假设并输出完整估值报告。

> ⚠️ 本项目仅用于研究与教学演示，**不构成任何投资建议**。

## 快速开始

```bash
# 1. 安装依赖（项目已用 .venv 虚拟环境）
.venv/Scripts/python.exe -m pip install requests

# 2. 运行（默认贵州茅台 600519.SH）
.venv/Scripts/python.exe -m dcf.run_dcf 600519.SH

# 3. 指定其他标的
.venv/Scripts/python.exe -m dcf.run_dcf 000858.SZ   # 五粮液（深市）
.venv/Scripts/python.exe -m dcf.run_dcf 00700.HK    # 腾讯控股（港股）
```

## 目录结构

```
dcf/
```

## 模型结构

```
历史财务数据（利润表 / 现金流量表 / 资产负债表）
        │  推导驱动假设（CAGR、利润率、资本密集度）
        ▼
假设区 DCFAssumptions（所有输入独立存放，蓝=输入）
        │
        ▼
FCFF = EBIT×(1-t) + D&A − Capex − ΔNWC   （5 年显式预测）
        │
        ▼
WACC = E/V×Ke + D/V×Kd×(1-t)   （Ke = Rf + β×ERP）
        │
        ▼
终值 TV = FCFF₅×(1+g) / (WACC − g)   （Gordon 永续增长）
        │
        ▼
企业价值 EV → 股权价值 = EV − 净债务 → 每股价值
        │
        ▼
敏感性分析（WACC × g 双变量矩阵）
```

## 关键假设（可在 `engine.py` 的 `DCFAssumptions` 中覆盖）

| 假设 | 默认值 | 说明 |
|------|--------|------|
| 预测期 | 5 年 | 显式预测年数 |
| 营收增速 | 由历史 CAGR 衰减 | 高增长向长期均值回落 |
| EBIT 利润率 | 由净利率/税率回推 | 保持稳定 |
| 无风险利率 Rf | 2.5% | 10 年期国债 |
| 股权风险溢价 ERP | 6.0% | 市场风险溢价 |
| Beta | 1.0 | 需按个股调整 |
| 债务成本 Kd | 4.0% | 税前 |
| 永续增长率 g | 3.0% | 不得超过长期 GDP 增速 |

## 建模规范

遵循投行建模颜色与规范约定：

- **蓝色**：硬编码输入（假设区，用户可改）
- **黑色**：公式计算
- **绿色**：跨模块引用（历史数据 → 假设推导）
- 假设独立存放，公式全程引用无硬编码
- 关键假设（WACC、g）配敏感性分析
- 终值占比 > 70% 时自动警示
- 假设越界自动抛错，拒绝"反推结论"

## 数据来源与免责

- 数据来自东方财富公开 F10 接口，仅供研究演示，版权归原发布方所有。
- 抓取依赖网络，公司代理环境下已配置绕过（`trust_env=False`）。
- 财务数据以最近一期年报为基准，季度数据不纳入。
