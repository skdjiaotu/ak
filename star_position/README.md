# 科创板位置监控 —— 高位风险提示 / 低位建仓信号

判断科创50（000688）当前位置是「高位（危险）」还是「低位（可建仓）」，
输出 5 档信号 + 建议仓位，与 `gem_position`（创业板）对称。

## 运行方式

```bash
# 命令行报告
.venv/Scripts/python.exe -m star_position.run

# 生成可视化驾驶舱
.venv/Scripts/python.exe -m star_position.dashboard
```

驾驶舱输出：`reports/科创板位置驾驶舱_YYYY-MM-DD.html`。

## 位置温度模型（与创业板版的核心差异）

| 要素 | 创业板权重 | 科创板权重 | 原因 |
|------|-----------|-----------|------|
| 价格分位 | 40% | **35%** | 科创板盈利波动大，价格分位易失真 |
| 估值分位 | 40% | **45%** | 估值是科创板的核心矛盾 |
| 距高点回撤 | 20% | 20% | |

## 关键洞察：科创50「跌了但没变便宜」

这是科创板监控最有价值的发现，与创业板形成鲜明对比：

| 指标 | 创业板指 | 科创50 |
|------|---------|--------|
| 距高点回撤 | -43.8% | -45.8% |
| PE 历史分位 | 5.4%（极低） | **74.5%（偏高）** |
| PE-TTM | 24 倍 | **90 倍** |
| ROE | — | **6.1%** |
| 位置温度 | 36 🟢 偏低 | **66 🟠 偏高** |
| 建议仓位 | 80% | **40%** |

同样是回撤近半，创业板是「真便宜」可建仓，科创50 是「跌了但没变便宜」反而偏高——
因为半导体成分股盈利恶化（ROE 仅 6%），PE 高达 90 倍仍处历史 74.5% 分位。

引擎对「价格低位 + 估值高位」的背离场景显式红色警示，避免把技术超跌误判为估值便宜。
