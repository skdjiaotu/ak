# A 股恐慌指数（已实现波动率版）

用"20 日已实现波动率（年化）"作为美股 VIX 的 A 股近似代理，衡量市场恐慌程度。

> ⚠️ 仅基于公开数据，不构成投资建议。

## 快速开始

```bash
.venv/Scripts/python.exe -m pip install akshare requests

# 沪深300 恐慌指数（默认）
.venv/Scripts/python.exe -m vix.run

# 指定指数
.venv/Scripts/python.exe -m vix.run 创业板指

# 全部指数对比
.venv/Scripts/python.exe -m vix.run all
```

## 原理

美股 VIX 基于期权隐含波动率（预期未来 30 天）。A 股无官方 VIX，用已实现波动率近似：

```
日收益率  r_t = ln(P_t / P_{t-1})
20 日波动率 σ = std(r) × √252   （年化）
```

σ 越高，短期波动越大，情绪越恐慌。

## 恐慌等级（按历史分位）

| 分位 | 等级 | 含义 |
|------|------|------|
| ≥ 90% | 🔴 极度恐慌 | 波动率历史高位 |
| 70%~90% | 🟠 恐慌 | 明显恐慌 |
| 40%~70% | 🟡 中性 | 正常波动 |
| 15%~40% | 🟢 平静 | 情绪平稳 |
| < 15% | 🔵 极度平静 | 注意低波动常伴变盘 |

## 数据源

- 新浪财经：指数历史日 K（沪深300 约 3 年）

## 与估值指标的配合

恐慌指数（波动率）与估值分位是两个互补维度：

- **高波动 + 低估值分位**：恐慌性下跌，可能超卖（如当前创业板）
- **低波动 + 高估值分位**：情绪稳定但估值贵（如当前上证50）

两者结合能更全面地判断市场状态。
