# 科创50 位置危险度评估

量化评估科创50（000688）当前位置的"危险程度"，复用 `gem_risk` 包的评分引擎。

> ⚠️ 仅基于公开数据与经验阈值的量化参考，**不构成投资建议**。

## 快速开始

```bash
# 安装依赖（akshare + requests）
.venv/Scripts/python.exe -m pip install akshare requests

# 运行科创50 评估
.venv/Scripts/python.exe -m star_risk.run
```

## 与创业板评估的差异

| 项目 | 创业板指 (399006) | 科创50 (000688) |
|------|-------------------|-----------------|
| 估值数据源 | 国证官网 + 乐咕乐股 | 蛋卷基金（danjuanfunds） |
| PE 分位口径 | 创业板50 历史序列自算 | 蛋卷直接给完整历史分位 |
| 关键差异 | 乐咕乐股无"创业板指"，用创业板50 近似 | 中证官网只给近20期，改用蛋卷完整历史 |

## 数据源

- **蛋卷基金**（danjuanfunds.com）：科创50 当前 PE/PB + 完整历史分位（最权威）
- **新浪财经**：科创50 历史日 K（均线、回撤、量能）
- **乐咕乐股**：全市场 PE（资金面温度）

## 关键洞察：科创50 "跌了但没变便宜"

科创50 与创业板的一个关键区别是：

- 价格已从 250 日高点回撤约 47%，技术上处于低位
- 但 **PE 仍处于历史 74.5% 的高分位**（PE≈90 倍）

这是因为科创50 成分股（半导体等）**盈利在恶化**（指数 ROE 仅 6%），价格跌的同时
盈利跌得更快，导致"跌了但估值没降"。评估引擎对此专门加了黄灯警示，避免把
"技术超跌"误判为"估值便宜"。
