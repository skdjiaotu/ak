# trade_log —— 交易日志台账

记录每次交易（买入/卖出）的**原因**与**事后复盘**，用于事后总结交易纪律、识别自己的投资行为模式。

存储：`trade_log/data.db`（SQLite）

## 核心字段

| 字段 | 说明 |
|------|------|
| code / name | 股票代码 / 名称 |
| direction | buy 买入 / sell 卖出 |
| trade_date | 交易日期 |
| price / shares / amount | 成交价 / 数量 / 金额（自动计算） |
| **reason** | **交易原因（核心）** |
| **review** | **事后复盘（可选）** |
| tags | 标签（如「价值投资」「止盈」） |
| note | 备注 |

## 使用方式

后台页面：http://127.0.0.1:8765/trade（从持仓页/策略台账页右上角导航进入）

- 记录交易：点击「+ 记录一笔交易」，填写方向、代码、价格、数量、**原因**。
- 事后复盘：点「编辑」补充 `review` 字段，回看这笔交易做对没有。
- 筛选：按方向（买/卖）和代码过滤。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/trade` | 交易列表 + 统计 |
| POST | `/api/trade` | 新增交易 |
| PUT | `/api/trade/{id}` | 更新交易 |
| DELETE | `/api/trade/{id}` | 删除交易 |

## 设计理念

「交易原因 + 事后复盘」是核心：只记录买卖动作没有意义，记录「为什么」，
一段时间后回看，才能发现自己是在**做投资**还是**在做情绪**（追涨杀跌、频繁交易等）。
