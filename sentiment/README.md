# 市场情绪驾驶舱 —— 七因子情绪择时看板

静态 HTML 驾驶舱，一页看全「市场情绪 + 资金面 + 回测绩效」。

## 运行方式

```bash
.venv/Scripts/python.exe -m sentiment.dashboard
```

输出：`reports/市场情绪驾驶舱_YYYY-MM-DD.html`（自包含，含 ECharts，双击即看）。

## 驾驶舱内容

| 区块 | 内容 |
|------|------|
| 综合情绪仪表盘 | 七因子合成的情绪热度（-2~+2），映射建议仓位 |
| 择时回测绩效 | 沪深300：买入持有 vs 情绪择时 vs 反向对照（累计/年化/回撤/夏普） |
| 七因子状态卡 | 换手率·成交额·融资余额·新增开户·基金发行·股债性价比·波动率，各当前值+近3年分位 |
| 净值曲线 | 策略 vs 买入持有净值（ECharts） |
| 仓位曲线 | 历史建议仓位（0~1） |
| 因子有效性 | 单因子 IC 与方向是否符合预期 |

## 核心结论（回测揭示）

- 本策略为**情绪逆向择时**（过热→减仓，冰点→加仓）。
- 回测（2006~2026，246 个月）显示：情绪逆向择时累计 **-13%**，跑输买入持有（+240%），
  更跑输**反向信号**（+367%）。
- 原因：换手率/成交额/新增开户数三个「热度」因子的 IC 均为正 —— **A 股是动量市，
  越热越涨**，逆向逻辑在这些因子上不成立。
- 实用定位：情绪因子更适合做**风险警示**（识别过热泡沫），而非直接逆向抄底。

## 数据源与约束

| 因子 | 数据源 | 频率 | 约束 |
|------|--------|------|------|
| 换手率/成交额 | 腾讯沪深300日线 | 日→月 | 2005 起，完整 |
| 融资余额 | 东财两融汇总 | 日→月 | 2012-06 起 |
| 新增开户数 | 中登 | 月 | 2015-04 起，2023-08 停更 |
| 基金发行热度 | 东财新发基金 | 月聚合 | 仅 2023 年起回溯 |
| 股债性价比 | 乐咕PE + 10Y国债 | 月 | 2005 起 |
| 波动率 | 沪深300 历史波动率 HV20 | 日→月 | 2005 起（QVIX 源不稳定，已改用 HV20 兜底） |

数据仅供研究参考，不构成投资建议。
