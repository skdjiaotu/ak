# 创业板位置危险度评估

量化评估创业板指（399006）当前位置的"危险程度"，从四个维度综合研判，输出红/黄/绿灯判定。

> ⚠️ 仅基于公开数据与经验阈值的量化参考，**不构成投资建议**。

## 快速开始

```bash
# 安装依赖（akshare + requests）
.venv/Scripts/python.exe -m pip install akshare requests

# 运行评估
.venv/Scripts/python.exe -m gem_risk.run
```

## 四维指标体系

| 维度 | 指标 | 数据源 |
|------|------|--------|
| 估值分位 | PE-TTM / PB 历史分位、股债性价比 ERP | 国证指数官方 + 乐咕乐股 |
| 技术结构 | 均线乖离、距前高回撤、年内涨跌幅 | 新浪财经日 K |
| 情绪与杠杆 | 量能比（20日/60日） | 新浪财经日 K |
| 资金面 | 全市场 PE 温度 | 乐咕乐股 |

## 危险度判定逻辑

每个指标归一化为 0~100 分（越高越危险），加权汇总：

| 指标 | 权重 | 说明 |
|------|------|------|
| PE 分位 | 30% | 估值核心 |
| PB 分位 | 15% | |
| 均线乖离 | 15% | 短期过热/超跌 |
| 距前高回撤 | 10% | 追高风险 |
| 年内涨幅 | 15% | |
| 量能 | 15% | 情绪亢奋信号 |

**信号判定**：
- 🔴 红灯（危险）：综合分 ≥ 70，或 PE 分位 ≥ 90%
- 🟡 黄灯（警惕）：综合分 40~70
- 🟢 绿灯（安全）：综合分 < 40

## 数据源说明

- **国证指数官网**（cnindex.com.cn）：创业板指官方 PE/PB、点位、成交额
- **乐咕乐股**（legulegu.com，经 akshare）：创业板50 历史 PE/PB 序列、全市场 PE
- **新浪财经**（sina.com.cn）：创业板指历史日 K

> 注：乐咕乐股不直接提供"创业板指"，用高度相关的**创业板50**历史估值序列近似分位；
> 当前 PE 用国证官方创业板指值。

## 网络说明
