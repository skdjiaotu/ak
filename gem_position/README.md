# 创业板位置评估 —— 高位风险提示 / 低位建仓信号

聚焦一个目标：判断创业板指（399006）当前处于历史**高位（危险）**还是**低位（可建仓）**，
输出 5 档信号 + 建议仓位。

## 运行方式

```bash
# 命令行报告
.venv/Scripts/python.exe -m gem_position.run

# 生成可视化驾驶舱
.venv/Scripts/python.exe -m gem_position.dashboard
```

驾驶舱输出：`reports/创业板位置驾驶舱_YYYY-MM-DD.html`（自包含，双击即看）。

## 位置温度模型

位置温度 = 三要素加权（0~100，越高越危险）：

| 要素 | 权重 | 含义 |
|------|------|------|
| 价格分位 | 40% | 当前点位在历史日收盘中的分位（近5年为主） |
| 估值分位 | 40% | PE-TTM 历史分位（创业板50 序列，PB 辅助） |
| 距高点回撤 | 20% | 离近5年高点的距离，回撤越浅越危险 |

**五档信号**：

| 温度 | 信号 | 建议仓位 |
|------|------|---------|
| ≥80 | 🔴 高风险 | 20%（轻仓/止盈） |
| 60~80 | 🟠 偏高风险 | 40% |
| 40~60 | 🟡 中性 | 60% |
| 20~40 | 🟢 偏低位置 | 80% |
| <20 | 🟢 低位区域 | 100%（越跌越买） |

## 关键设计：估值分位 vs 价格分位

⚠️ **光看价格分位会误判**。创业板指从 2010 年 1000 点涨到 2000+，全历史价格分位天然偏高，
但不代表「贵」——因为盈利增长抬高了点位。因此本模型**估值分位权重与价格分位相同（各 40%）**，
用「跌了是否真的变便宜」来校正。

典型背离场景（如 2026-11 当前）：价格近5年分位 57%（中高），但 PE 分位仅 5%（极低）——
说明「跌了且真的变便宜」，综合温度被估值拉低，给出偏低位置信号。
