# 2026-11-02 工作日志

## 市场情绪多因子择时策略 + 驾驶舱

新增 `sentiment/` 模块（7 因子情绪择时策略，对标沪深300）：

- `fetcher.py`：采集换手率/成交额（腾讯沪深300日线）、融资余额（东财两融）、
  新增开户数（中登）、基金发行热度（东财新发基金）、股债性价比（PE+10Y国债）、
  波动率（HV20 历史波动率，替代不稳定的 QVIX 源）。统一月度面板，带 pickle 缓存。
- `engine.py`：滚动 z-score 标准化 + 方向符号 + 等权合成情绪热度 + 热度→仓位映射。
- `backtest.py`：月度调仓回测，对比买入持有/反向信号，参数敏感性。
- `run.py`：命令行报告入口。
- `dashboard.py`：生成静态 HTML 驾驶舱（ECharts），输出 `reports/市场情绪驾驶舱_*.html`。

### 关键结论（回测实证）
- 情绪逆向择时（过热减仓/冰点加仓）累计 -13%，跑输买入持有(+240%)和反向信号(+367%)。
- 换手率/成交额/开户数 IC 为正 → A股是动量市，情绪因子更适合做"过热风险警示"而非逆向抄底。

### 数据源踩坑备忘
- 东财 push2 行情接口易限流（短时间内请求过多会断连），换手率/成交额改走腾讯源
  `stock_zh_index_daily_tx`（含 amount 字段，2005 起无缺口）。
- 新浪指数 `stock_zh_index_daily` 的 volume 历史有大段缺失（2015-2023），不可用。
- QVIX 源 `1.optbbs.com` 极不稳定（403/超时），改用沪深300 20日历史波动率 HV20 兜底。
- 新增开户数 2023-08 后停更；基金发行接口仅回溯 2023 年。

## 创业板位置评估模块 + 驾驶舱

新增 `gem_position/` 模块（聚焦"创业板高位风险/低位建仓"信号）：

- `fetcher.py`：新浪创业板指日K（价格分位/距高点/均线）+ 乐咕创业板50 PE/PB + 国证当前估值。
- `engine.py`：位置温度 = 价格分位40% + 估值分位40% + 距高点回撤20%，映射5档信号+建议仓位。
- `run.py` / `dashboard.py`：命令行报告 + HTML驾驶舱（输出 `reports/创业板位置驾驶舱_*.html`）。

### 关键设计
- 价格分位会因指数长期上涨而天然偏高，故估值分位与价格分位同权重（各40%），用"跌了是否真变便宜"校正。
- 创业板指新浪日K可取 2010-06 至今（约3986条），历史最高 4372（2026-06-25）。
- 当前(2026-11-02)：点位2458.7，PE分位5.4%（极低），位置温度36 → 偏低位置，建议仓位80%。
